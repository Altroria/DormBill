# 服务器部署命令

## 1. 更新代码并重新构建

```bash
cd /root/workspace/DormBill

# 拉取最新代码
git pull

# 重新构建并启动后端
docker compose -f docker-compose.prod.yml build backend
docker compose -f docker-compose.prod.yml up -d backend

# 查看后端日志
docker compose -f docker-compose.prod.yml logs -f backend
```

## 2. 导入入住数据

```bash
cd /root/workspace/DormBill

# 删除之前的测试数据
docker exec -i dormbill-mysql mysql -uroot -p405649 dormbill -e "DELETE FROM residence_records;"

# 导入入住数据（使用utf8mb4编码）
docker exec -i dormbill-mysql mysql -uroot -p405649 --default-character-set=utf8mb4 dormbill < scripts/import_residences.sql

# 验证导入结果
docker exec -it dormbill-mysql mysql -uroot -p405649 --default-character-set=utf8mb4 dormbill -e "
SELECT COUNT(*) as total FROM residence_records;
"

# 查看前10条记录
docker exec -it dormbill-mysql mysql -uroot -p405649 --default-character-set=utf8mb4 dormbill -e "
SELECT r.id, e.name, e.company, rm.room_no, b.building_no, r.check_in_date, r.status, r.remark
FROM residence_records r 
JOIN employees e ON r.employee_id = e.id 
JOIN rooms rm ON r.room_id = rm.id 
JOIN buildings b ON rm.building_id = b.id 
ORDER BY r.id
LIMIT 10;
"
```

## 3. 常用命令

### 查看容器状态
```bash
docker compose -f docker-compose.prod.yml ps
```

### 重启所有服务
```bash
docker compose -f docker-compose.prod.yml restart
```

### 重启单个服务
```bash
docker compose -f docker-compose.prod.yml restart backend
docker compose -f docker-compose.prod.yml restart frontend
docker compose -f docker-compose.prod.yml restart mysql
```

### 查看日志
```bash
# 后端日志
docker compose -f docker-compose.prod.yml logs -f backend

# 前端日志
docker compose -f docker-compose.prod.yml logs -f frontend

# 数据库日志
docker compose -f docker-compose.prod.yml logs -f mysql
```

### 停止所有服务
```bash
docker compose -f docker-compose.prod.yml down
```

### 启动所有服务
```bash
docker compose -f docker-compose.prod.yml up -d
```

## 4. 数据库维护

### 备份数据库
```bash
docker exec dormbill-mysql mysqldump -uroot -p405649 --default-character-set=utf8mb4 dormbill > backup_$(date +%Y%m%d_%H%M%S).sql
```

### 恢复数据库
```bash
docker exec -i dormbill-mysql mysql -uroot -p405649 --default-character-set=utf8mb4 dormbill < backup_file.sql
```

### 查看数据统计
```bash
docker exec -it dormbill-mysql mysql -uroot -p405649 --default-character-set=utf8mb4 dormbill -e "
SELECT 
  '楼栋数量' as type, COUNT(*) as count FROM buildings
UNION ALL SELECT '房间数量', COUNT(*) FROM rooms
UNION ALL SELECT '员工数量', COUNT(*) FROM employees
UNION ALL SELECT '入住记录', COUNT(*) FROM residence_records;
"
```

## 5. 问题排查

### 如果后端无法连接数据库
```bash
# 检查网络
docker network ls
docker network inspect dormbill_dormbill-network

# 检查数据库健康状态
docker compose -f docker-compose.prod.yml ps mysql
```

### 如果前端无法访问
```bash
# 检查nginx配置
docker exec dormbill-frontend cat /etc/nginx/nginx.conf

# 测试后端API
curl http://localhost:8000/health
```

## 注意事项

1. **字符编码**：所有MySQL操作都要加上 `--default-character-set=utf8mb4`
2. **密码**：数据库root密码是 `405649`
3. **端口**：前端对外端口80，后端和数据库仅内网访问
4. **导入顺序**：先导入楼栋和房间，再导入员工，最后导入入住记录
