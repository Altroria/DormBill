# 宿舍费用按天分摊说明文档

## 📋 概述

本系统对**所有费用**实行按天分摊，包括：
- ✅ 房租
- ✅ 公共电费
- ✅ 空调费
- ✅ 水费

无论是正常入住、中途搬离，还是换房，都严格按照**实际入住天数**进行费用分摊。

---

## 1️⃣ 房租分摊（按天）

### 计算公式
```
应收房租 = 房租标准 × (实际入住天数 / 当月总天数) - 免租金额
```

### 关键逻辑
- **实际入住天数**：从入住日到搬离日（含）
- **免租处理**：试用期内的天数不收费
- **搬离处理**：`check_out_date` 是最后一天住的日期（包含这一天）

### 代码位置
- `backend/app/services/rent_service.py` - `calculate_rent_actual()`

### 示例
```
场景：9月1日入住，9月14日搬离，房租标准500元
计算：500 × (14/30) = 233.33元
```

---

## 2️⃣ 电费分摊（按天）

### 包含内容
- 公共用电费用
- 空调费用（如有）

### 计算公式
```
个人电费 = 房间总电费 × (个人入住天数 / 房间总人天数)
```

### 关键逻辑
1. **房间总人天数**：所有住户的入住天数总和
   ```
   例如：3人房间，9月份
   - A住了14天
   - B住了30天  
   - C住了30天
   → 房间总人天数 = 14 + 30 + 30 = 74天
   ```

2. **个人分摊比例**：`个人天数 / 总人天数`
   ```
   A的分摊比例 = 14 / 74 = 18.92%
   ```

3. **排除无效记录**：
   - `status == "invalid"` 的记录不参与分摊
   - 入住天数 ≤ 0 的不参与分摊

### 代码位置
- `backend/app/services/electricity_calculation_service.py` - `calculate_room_electricity()`
- `backend/app/services/electricity_service.py` - `allocate_air_conditioning_fee()`

### 示例
```
场景：3人房间，9月公共电费300元
- A: 14天
- B: 30天
- C: 30天
→ 总人天数: 74天

A的电费: 300 × (14/74) = 56.76元
B的电费: 300 × (30/74) = 121.62元
C的电费: 300 × (30/74) = 121.62元
```

---

## 3️⃣ 水费分摊（按天）

### 计算公式
```
个人水费 = 房间总水费 × (个人入住天数 / 房间总人天数)
```

### 关键逻辑
- 与电费分摊逻辑完全相同
- 按实际入住天数的比例分摊
- 排除无效记录和特殊情况（如出差）

### 代码位置
- `backend/app/services/water_meter_service.py` - `calculate_room_water_fee()`

### 示例
```
场景：2人房间，9月水费100元
- A: 16天
- B: 30天
→ 总人天数: 46天

A的水费: 100 × (16/46) = 34.78元
B的水费: 100 × (30/46) = 65.22元
```

## 4️⃣ 换房场景处理

### 场景说明
员工从A房间换到B房间，例如：9月15日换房

### 处理逻辑

#### 旧房记录
```python
check_out_date = transfer_date - 1天  # 9月14日（最后一天住旧房）
status = "leave"  # 已搬离
```

#### 新房记录
```python
check_in_date = transfer_date  # 9月15日（第一天住新房）
status = "valid"  # 有效
```

### 费用计算
所有费用分别计算后相加：

#### 房租
```
旧房租：500 × (14/30) = 233.33元
新房租：600 × (16/30) = 320.00元
总房租：233.33 + 320.00 = 553.33元
```

#### 电费
```
旧房电费：300 × (14/74) = 56.76元  (假设旧房3人，总74人天)
新房电费：200 × (16/46) = 69.57元  (假设新房2人，总46人天)
总电费：56.76 + 69.57 = 126.32元
```

#### 水费
```
同电费逻辑，分别计算后相加
```

### 代码位置
- `backend/app/routers/residences.py` - `batch_transfer()`

### 修复要点
✅ **已修复**：旧房`check_out_date`改为`transfer_date - 1天`，避免重复计费
- 修复前：15日会被计入旧房和新房，导致重复计费
- 修复后：14日是旧房最后一天，15日是新房第一天，无重复

## 6️⃣ 关键日期工具函数

### `stay_days_in_month()` - 计算入住天数

```python
def stay_days_in_month(
    check_in: date,
    check_out: date | None,
    target_month: date,
    check_out_exclusive: bool = False,
) -> int:
    """
    计算员工在target_month月的有效入住天数
    
    公式：min(搬离日, 月末) - max(入住日, 月初) + 1
    
    check_out_exclusive=True: 搬离日不计费（用于特殊场景）
    """
```

**代码位置**：`backend/app/utils/date_utils.py`

### 关键点
- `check_out_date` 的含义：**最后一天住的日期（包含这一天）**
- 计算天数时使用 `+1`（闭区间）
- `None` 表示未搬离，计算到月末

## 8️⃣ 总结

### 所有费用均按天分摊 ✅

| 费用类型 | 分摊方式 | 公式 |
|---------|---------|------|
| **房租** | 按个人入住天数 | `房租标准 × (个人天数/月总天数)` |
| **电费** | 按房间人天数比例 | `房间电费 × (个人天数/房间总人天数)` |
| **空调费** | 按房间人天数比例 | `房间空调费 × (个人天数/房间总人天数)` |
| **水费** | 按房间人天数比例 | `房间水费 × (个人天数/房间总人天数)` |

### 特殊场景处理 ✅

| 场景 | 处理方式 |
|------|---------|
| **换房** | 两个房间分别计算，避免重复计费 |
| **搬离** | 搬离日是最后一天（含），之后不计费 |
| **试用期** | 免租期内按天扣除房租 |

### 关键原则
1. **公平性**：严格按实际入住天数分摊
2. **准确性**：避免重复计费或遗漏
3. **透明性**：计算公式清晰明确
