### 2. 水费分摊改为按天计算
**文件**: `backend/app/services/water_meter_service.py`

**修改内容**:
- ✅ 水费：从半月规则（住满15天）改为按入住天数比例分摊
- ✅ 包含已搬离（`status='leave'`）的员工参与分摊
- ✅ 计算公式：`个人水费 = 房间总水费 × (个人天数 / 房间总人天数)`

**关键代码变化**:
```python
# 修改前（半月规则+按人数）
valid_count = 0
for res in all_residences:
    if stay_days > 15:  # 半月规则
        valid_count += 1
per_person_fee = total_fee / valid_count

# 修改后（按天数）
total_days = 0
employee_days = {}
for res in all_residences:
    days = stay_days_in_month(...)
    if days > 0:
        employee_days[res.employee_id] = days
        total_days += days
per_person_fee = total_fee × (employee_days[employee_id] / total_days)
```

### 3. 修复换房重复计费问题
**文件**: `backend/app/routers/residences.py`

**修改内容**:
- ✅ 旧房`check_out_date`改为`transfer_date - 1天`（避免重复计费）
- ✅ 旧房状态改为`leave`（而非`invalid`）
- ✅ 新房继承`is_primary_payer`状态

**关键代码变化**:
```python
# 修改前（存在重复计费）
old_res.check_out_date = transfer_date  # 9月15日
new_res.check_in_date = transfer_date   # 9月15日
# 结果：15日被计入两个房间，重复计费

# 修改后（无重复）
old_res.check_out_date = transfer_date - timedelta(days=1)  # 9月14日
old_res.status = "leave"
new_res.check_in_date = transfer_date  # 9月15日
new_res.is_primary_payer = old_res.is_primary_payer  # 继承
# 结果：14日旧房最后一天，15日新房第一天，无重复
```

### 统一的分摊公式

#### 房租
```
个人房租 = 房租标准 × (个人入住天数 / 当月总天数)
```

#### 电费/空调费/水费
```
个人费用 = 房间总费用 × (个人入住天数 / 房间总人天数)
```

## 🎯 回答用户问题

### 问题：如果一个人从A转租到B，所有费用都按天分摊吗？

### ✅ 答案：是的！

**房租** - 按天分摊 ✅
```
旧房租: 500 × (14天/30天) = 233.33元
新房租: 600 × (16天/30天) = 320.00元
总计: 553.33元
```

**电费** - 按天分摊 ✅
```
旧房电费: 300 × (14天/74人天) = 56.76元
新房电费: 200 × (16天/46人天) = 69.57元
总计: 126.32元
```

**空调费** - 按天分摊 ✅
```
与电费相同逻辑，按入住天数比例分摊
```

**水费** - 按天分摊 ✅
```
与电费相同逻辑，按入住天数比例分摊
```

### 关键原则
1. **无重复计费**：换房日期处理正确，旧房14日是最后一天，新房15日是第一天
2. **按实际天数**：所有费用严格按实际入住天数比例分摊
3. **公平合理**：住得多的承担多，住得少的承担少
