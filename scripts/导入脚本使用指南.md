## 🔍 数据处理逻辑

### 1. 楼栋处理

- 从 Excel 提取唯一楼号
- 自动生成楼栋名称（247号楼、248号楼等）
- 99号楼标记为"特殊宿舍区"

### 2. 房间处理

- **去重规则**: (楼号, 房号, 室号) 组合唯一
- **电价**: 统一设置为 0.49 元/度
- **房租**: 直接从 Excel "房租"列获取

### 3. 员工处理

- **去重规则**: 姓名唯一（同名视为同一人）
- **工号生成**: EMP1001 开始自增
- **备注保留**: 保留 Excel 中的所有备注信息

### 4. 入住记录处理

#### 主要缴费人判断

```
if 房租 > 0:
    is_primary_payer = 1  # 主缴费人
else:
    is_primary_payer = 0  # 配偶或免租人员
```

#### 试用期识别

```
if "试用" in 备注 or "前3个月" in 备注 or "前三个月" in 备注:
    probation_months = 3
else:
    probation_months = 0
```

#### 状态判断

```
if "离宿" in 备注:
    status = 'invalid'  # 已离宿
else:
    status = 'valid'    # 在住
```

## ⚠️ 重要注意事项

### 1. 数据备份

**导入前务必备份数据库！**

```bash
# 备份整个数据库
mysqldump -u root -p dormbill > backup_20260912.sql

# 备份特定表
mysqldump -u root -p dormbill buildings rooms employees residence_records > backup_tables.sql
```

### 2. 数据清空警告

⚠️ `import_all_data.sql` 会执行以下操作：

```sql
SET FOREIGN_KEY_CHECKS = 0;
TRUNCATE TABLE residence_records;
TRUNCATE TABLE employees;
TRUNCATE TABLE rooms;
TRUNCATE TABLE buildings;
SET FOREIGN_KEY_CHECKS = 1;
```

这将**永久删除**这些表中的所有数据！

### 3. 字符编码

确保 MySQL 使用正确的字符编码：

```sql
-- 查看数据库编码
SHOW CREATE DATABASE dormbill;

-- 应该显示
CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci
```

### 4. 外键约束

导入脚本会临时禁用外键检查，确保：
- 数据库支持 InnoDB 引擎
- 表之间的外键关系已正确定义

## 🐛 常见问题排查

### Q1: 导入时提示数据库不存在

**错误信息**: `ERROR 1049 (42000): Unknown database 'dormbill'`

**解决方法**:
```sql
CREATE DATABASE dormbill CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### Q2: 导入时提示表不存在

**错误信息**: `ERROR 1146 (42S02): Table 'dormbill.buildings' doesn't exist`

**解决方法**:
```bash
cd backend
alembic upgrade head
```

### Q3: 字符显示乱码

**解决方法**:
```sql
-- 设置客户端字符集
SET NAMES utf8mb4;

-- 或在连接时指定
mysql -u root -p --default-character-set=utf8mb4 dormbill
```

### Q4: 入住记录导入失败

**可能原因**:
- 员工姓名不匹配（多余空格）
- 房间信息不匹配
- 外键约束问题

**排查方法**:
```sql
-- 查找未匹配的员工
SELECT DISTINCT t.emp_name
FROM temp_residence_data t
LEFT JOIN employees e ON e.name = t.emp_name
WHERE e.id IS NULL;

-- 查找未匹配的房间
SELECT DISTINCT t.building_no, t.room_no, t.room_unit
FROM temp_residence_data t
LEFT JOIN rooms r ON r.room_no = t.room_no AND r.room_unit = t.room_unit
LEFT JOIN buildings b ON b.id = r.building_id AND b.building_no = t.building_no
WHERE r.id IS NULL;
```

### Q5: 验证脚本连接失败

**错误信息**: `Can't connect to MySQL server`

**解决方法**:
1. 检查 `backend/app/config.py` 中的数据库配置
2. 确认 MySQL 服务正在运行
3. 检查防火墙设置

## 📝 数据更新流程

### 当 Excel 数据更新时

1. **更新 Excel 文件**
   ```
   data/房间和人员数据.xlsx
   ```

2. **重新生成 SQL**
   ```bash
   cd scripts
   python generate_import_sql.py
   ```

3. **备份现有数据**（重要！）
   ```bash
   mysqldump -u root -p dormbill > backup_before_update.sql
   ```

4. **执行导入**
   ```bash
   mysql -u root -p dormbill < import_all_data.sql
   ```

5. **验证结果**
   ```bash
   python verify_import.py
   ```

### 增量更新（不清空数据）

如果只想添加新数据而不清空现有数据：

1. 编辑 `import_all_data.sql`
2. 注释掉 TRUNCATE 语句：
   ```sql
   -- TRUNCATE TABLE residence_records;
   -- TRUNCATE TABLE employees;
   -- TRUNCATE TABLE rooms;
   -- TRUNCATE TABLE buildings;
   ```
3. 修改 INSERT 语句为 INSERT IGNORE（避免主键冲突）

## 🔧 高级用法

### 自定义导入规则

编辑 `generate_import_sql.py`，修改数据处理逻辑：

```python
# 示例：修改试用期判断逻辑
def is_probation(remark):
    keywords = ['试用', '前3个月', '前三个月', '实习']
    return any(kw in remark for kw in keywords)

# 示例：修改主缴费人判断
def is_primary_payer(rent, remark):
    if rent > 0:
        return 1
    if '配偶' in remark or '夫妻' in remark:
        return 0
    return 1
```

### 添加自定义验证

编辑 `verify_import.py`，添加业务规则检查：

```python
# 示例：检查房租是否合理
result = session.execute(text("""
    SELECT room_name, rent_standard
    FROM rooms
    WHERE rent_standard < 0 OR rent_standard > 1000
"""))

for row in result:
    print(f"  ⚠️  异常房租: {row[0]} - ¥{row[1]}")
```

### 导出验证报告

```bash
# 将验证结果保存到文件
python verify_import.py > verification_report.txt
```
